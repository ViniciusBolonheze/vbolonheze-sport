Como deseja abrir o SA?

Escolha entre importar um JSON, abrir os dados já salvos neste navegador ou começar com um banco novo. Importar substitui o banco atual; abrir os dados locais preserva o que já está guardado.

IMPORTAR JSON

Selecione um arquivo JSON completo para substituir os dados e arquivos/fotos salvos neste navegador.

MEMÓRIA DO NAVEGADOR

Abre os dados locais que o SA já guardou neste navegador, sem importar arquivo e sem apagar o banco.

ABRIR BANCO NOVO

Limpa o banco e as preferências salvos pelo SA neste navegador e abre uma base nova.

O JSON é criado e lido neste navegador; o SA não envia os dados esportivos a um servidor. Se compartilhar o arquivo por mensageiro ou nuvem, esse serviço receberá uma cópia.

LEMBRETE IMPORTANTE

Exporte antes de sair

Antes de fechar o SA, exporte o banco completo em JSON para guardar uma cópia atualizada dos seus dados e fotos. O botão fica no cabeçalho, ao lado de Personalizar.

O banco de trabalho fica neste navegador. Se compartilhar o JSON por mensageiro ou serviço de nuvem, esse serviço receberá uma cópia.
Cópia local

Exportar dados

Escolha os módulos que deseja incluir. Todos começam marcados. O arquivo ZIP também será guardado em Banco de Dados/Exportacoes.

Restaurar dados locais

Importar backup

Selecione um backup ZIP criado pelo SA, marque os módulos e escolha o que fazer com os dados atuais.

Como importar desta vez?

A substituição pede uma confirmação adicional antes de alterar os dados.
